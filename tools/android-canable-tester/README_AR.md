# Hijjawi X CAN Lab - Android OTG v0.1

تطبيق Android مستقل لاختبار قطعة **MKS CANable V2.0 Pro** عن طريق وصلة USB OTG.

## التجربة
1. ثبت APK من GitHub Actions على Android 8+ يدعم USB OTG.
2. وصل CANable بكابل USB OTG بيانات، بدون توصيل CAN للسيارة أولاً.
3. افتح التطبيق واضغط فحص USB لرؤية VID/PID ونوع المنفذ.
4. إذا ظهرت SERIAL DRIVER، اضغط اتصال SLCAN، ووافق على إذن USB.
5. للإطارات الحقيقية، وصل فقط إلى ناقل CAN معروف وآمن، بجهد LV وأطراف مؤكدة، واختر السرعة الصحيحة.

## القيود
- هذا اختبار CAN الخام فقط؛ لا يفك خلايا Tesla أو BYD بعد.
- يحتاج SLCAN USB Serial؛ Firmware من نوع candleLight/gs_usb غير مدعوم في هذه النسخة. **لا تغير Firmware قبل تحديد النوع.**
- ترسل أوامر محلية C,Sx,L إلى المحول فقط؛ لا ترسل CAN frames.
- ظهور عدد رسائل = 0 أثناء عدم اتصال CAN بالشبكة أمر متوقع.
- لم يتم التحقق بعد على قطعة المستخدم فعلياً.
